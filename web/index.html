Table Read Tools

El teu guió, com mai l'havies vist.

Deixa que parlin els teus personatges.

Un plugin per al programa de guionatge Beat. Afegeix fotos als personatges i localitzacions, i converteix els diàlegs en una conversa tipus xat o en un lector de "table read" en directe.

Fotos de personatges i localitzacions Conversa tipus xat Table Read Mode 4 idiomes Exporta / Importa

Posa cara a cada personatge i localització

Arrossega una foto des del Finder sobre la targeta d'un personatge o localització, o copia una imatge i enganxa-la (⌘V). Les fotos es redimensionen i queden incrustades directament dins l'arxiu del guió — sense arxius externs ni enllaços trencats.

  • Reordena els personatges per importància amb ◀ ▶
  • Aquest ordre decideix qui protagonitza cada escena a la conversa i al lector

Llegeix el guió com una conversa

Cada escena es converteix en un xat: els diàlegs del protagonista a la dreta, la resta a l'esquerra amb el seu propi color, avatars a cada línia, una banda amb la foto de la localització, i una hora acumulada per a cada missatge.

  • Les línies d'acció apareixen com a avisos discrets i centrats
  • Cada escena acaba amb el temps total, ben visible

Table Read Mode

Un lector a pantalla completa, sense distraccions, per llegir el guió en veu alta. El cercle de qui parla s'il·lumina, amb un cronòmetre circular que mostra quant queda de la seva frase — calculat amb una estimació de velocitat de lectura, no a ull.

  • Reproducció automàtica, o pas a pas amb el teclat
  • Bombolla de text amb una cua tipus còmic que apunta a qui parla
  • Finestra redimensionable; res no es mou de lloc

Parla el teu idioma

La interfície del plugin està disponible en català, anglès, francès i èuscar — es detecta sola segons l'idioma del teu Mac la primera vegada que l'obres, i es pot canviar en qualsevol moment des de la capçalera.

Les fotos viuen dins del teu arxiu .fountain, així que hi viatgen soles. Exportar/Importar et permet reutilitzar les mateixes fotos en guions diferents, o guardar-ne una còpia de seguretat independent.

Instal·lació

Table Read Tools funciona totalment dins de Beat — no cal instal·lar res més.

macOS table-read-tools-latest-version-macos.zip
Descarrega
  1. Descomprimeix l'arxiu i copia la carpeta Table Read Tools.beatPlugin dins la carpeta de plugins de Beat: ~/Library/Containers/fi.KAPITAN.Beat/Data/Library/Application Support/Beat/Plugins/
  2. Reinicia Beat si ja el tenies obert.
  3. Obre un guió i vés a Tools → Table Read Tools.
