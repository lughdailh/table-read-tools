Table Read Tools

A plugin for Beat

Your script, like you've never seen it before.

Let your characters speak.

A plugin for the Beat screenwriting app. It adds photos to characters and locations, and turns your dialogue into a chat-style conversation or a live table-read player.

Character & location photos Chat-style conversation Table Read Mode 4 languages Export / Import

See it in action

Give every character and location a face

Drag a photo from Finder onto a character or location card, or copy an image and paste it (⌘V). Photos are resized and embedded straight into the screenplay file — no external files, no broken links.

  • Reorder characters by importance with ◀ ▶
  • That order decides who leads each scene in the conversation and player views

Read your script as a conversation

Every scene becomes a chat thread: the lead character's lines on the right, everyone else on the left in their own colour, avatars for every line, a photo banner for the scene's location, and a running timestamp for each message.

  • Action lines shown as quiet, centred notices
  • Each scene ends with a clear total scene time

Table Read Mode

A full-window, distraction-free player for reading the script out loud. The active speaker's circle glows, with a circular timer showing how much of the line is left — timed by an estimated reading speed, not by guesswork.

  • Automatic playback, or step through manually with the keyboard
  • Speech-bubble "stage" with a comic-style tail pointing to the speaker
  • Resizable window; the layout never jumps around

Speaks your language

The plugin's interface is available in Catalan, English, French, and Basque — auto-detected from your Mac the first time you open it, and switchable any time from the header.

Photos live inside your .fountain file, so they travel with it automatically. Export/Import lets you reuse the same photos across different scripts, or keep an independent backup.

Installation

Table Read Tools runs entirely inside Beat — nothing to install outside of it.

macOS table-read-tools-latest-version-macos.zip
Download
  1. Unzip the file and copy the Table Read Tools.beatPlugin folder into Beat's plugin folder: ~/Library/Containers/fi.KAPITAN.Beat/Data/Library/Application Support/Beat/Plugins/
  2. Restart Beat if it was already running.
  3. Open a screenplay, then go to Tools → Table Read Tools.
