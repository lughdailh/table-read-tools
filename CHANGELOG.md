# Changelog

All notable changes to Table Read Tools are documented in this file.

## 1.0.0 — 2026-08-03

- First stable release prepared for Beat's official Plugin Library.
- Added character and location photos stored with the screenplay.
- Added character importance ordering and chat-style conversation view.
- Added manual and automatic table-read playback.
- Added Catalan, English, French, and Basque interface languages.
- Added photo collection import and export.
- Prepared plugin metadata (description block and screenshot) for inclusion in the Beat Plugin Library.
- Added project screenshots and improved documentation.
- Removed the temporary debug console.
